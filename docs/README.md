# Documentation Index

The documentation set is now grouped by purpose so it is easier to locate product, architecture, and delivery information.

## Structure

- `product/` – Feature descriptions and product context.
- `architecture/` – System design and implementation details.
- `process/` – Roadmaps, user stories, and planning artifacts.
- `archive/` – Legacy wiki content retained for historical reference.
